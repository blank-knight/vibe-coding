# 工作原则（必须遵守）

1. **第一性原理优先**：先回答"为什么这样有效"，再谈"怎么做"
2. **审慎不假设**：路径不最短直接指出；前提不成立先停下讨论
3. **阶段推进**：不要一口气全做完，每阶段先输出结果再进下一阶段
4. **真实性优先**：以代码/数据为准，禁止 Mock/Stub/Demo 进生产
5. **成熟范式优先**：先找成熟轮子，自建是最后手段
